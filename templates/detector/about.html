Django System Architecture & MVT Pattern

This project has been architected using Django 5.0 following the standard Model-View-Template (MVT) design pattern. It integrates Scikit-learn for supervised machine learning and uses SQLite via the Django ORM for ACID-compliant persistence.

Model (ORM)

Defines Prediction, AuditLog, and Feedback schema in detector/models.py. Manages SQLite queries, migrations, and model methods without raw SQL.

View (Controller)

Handles HTTP requests in detector/views.py. Validates input using NewsAnalysisForm, executes TF-IDF transforms, runs the classifier, and returns rendered templates or JSON REST APIs.

Template (Presentation)

Django HTML templates in templates/detector/ utilizing template tags, CSRF tokens ({% csrf_token %}), template inheritance ({% extends %}), and Bootstrap 5 styling.

Django Built-in Security Features Active
  • Cross-Site Request Forgery (CSRF) protection on all POST endpoints.
  • SQL Injection prevention via parameterized Django ORM queries.
  • Cross-Site Scripting (XSS) protection via automatic template escaping.
  • Django Admin interface available at /admin/ for dataset auditing and user management.
