FAKE NEWS DETECTION SYSTEM

A state-of-the-art machine learning web application designed to counter disinformation by classifying news articles and headlines into REAL or FAKE using Natural Language Processing (NLP), TF-IDF statistical feature engineering, and regularized Logistic Regression.

Robust full-stack data science and web development ecosystem

End-to-end data processing and classification lifecycle

1. NLP Preprocessing Pipeline
  1. Lowercasing: Standardizes all text into uniform lower case to avoid case sensitivity discrepancies.
  2. Regex Stripping: Removes URL web links (`http://`, `https://`, `www.`), HTML tags, entities, and numeric noise.
  3. Punctuation Removal: Eliminates excessive question marks, exclamation marks, and typographical symbols.
  4. Stopword Filtering: Removes high-frequency grammatical tokens (e.g. `the`, `and`, `in`, `is`) that convey negligible semantic classification signal.
  5. Tokenization & Normalization: Tokenizes word boundaries and strips extra spaces into a coherent clean sequence.
2. TF-IDF & Logistic Classification

Term Frequency - Inverse Document Frequency (TF-IDF): Measures how important a word is to a document relative to the entire corpus:

TF-IDF(t, d, D) = TF(t, d) × log( |D| / (1 + DF(t, D)) )

Logistic Regression Classifier: Applies the standard logistic sigmoid function to predict the probability \( P(Y=1|X) \):

P(Fake|x) = 1 / (1 + e^-(w · x + b))
